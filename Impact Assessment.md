# Impact Summary
**Project:** Mountain Mama Media DAM and Rights Engine
**Requested By:** Director of Post-Production & Content Syndication
**Submitted To:** Change Control Board (CCB)

# Requested Changes
* Addition of automated video formatting into 6 format options upon ingestion
* Automated watermarking of editor's employee ID upon editing

# Impact
Scope: High impact. Adding these items would add 5+ new issues. Video processing and watermarking is not included in the current scope.
Schedule: High impact. Adding these items would displace the current schedule, affecting sprint 3 and final delivery.
Cost: High impact. Adding these items would produce additional costs, as each media file would be processed 6 times and a third-party service may be necessary to implement forensic watermarks.

# Team Recommendation
**Defer:**
* The features fit business model and values, but would affect the scope/schedule/cost too greatly.
* The addition of these items would displace the current sprint schedule and backlog. Because these items aren't integral to the function of the DAM, they can be evaluated at a later date
* Re-evaluate after core features are completed, before sprint 3

Keep the Sprint 3 commitment unchanged.
